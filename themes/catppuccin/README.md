# Catppuccin Theme

A soft, pastel-colored theme for quicklock based on the [Catppuccin Mocha](https://catppuccin.com/) palette.

## Colors

| Property | Color | Usage |
|---|---|---|
| `bg` | `#1e1e2e` | Background |
| `textPrimary` | `#f5c2e7` | Clock, date, password |
| `textStatus` | `#fab387` | Status messages |
| `textSecondary` | `#89b4fa` | Fingerprint subtitle |
| `textMuted` | `#94e2d5` | Hint text |
| `textHint` | `#a6e3a1` | Labels |
| `error` | `#f38ba8` | Auth failure |
| `spinnerStroke` | `#cba6f7` | Loading spinner |

## Usage

```bash
ln -sf themes/catppuccin/catppuccin.config.json config.json
```

Note: by default `bgImageOpacity` is set to `0.0` for a solid background. Set it to `0.6` to show the wallpaper.
